# Step-control gallery

Generated by `cargo run --release --example step_limit_gallery <res> <root>`.
Numbers and method: `../README.md`.

One directory per region; five modes per region; four panels per mode.

```text
  _uniform    the shipping bivariate colouring -- what gets displayed
  _outcome    terminal class, categorical
  _drift      energy drift, inferno, THE DIAGNOSTIC FIELD
  _errhot     error_ratio > 10, binary -- the artefact itself
```

**Every colour window is taken from the baseline and reused for every mode.** The spread
ramp is the baseline's own p1-p99, the drift ramp is a fixed constant, and the `errhot`
threshold is a fixed 10. An auto-ranged ramp per panel would stretch each mode's own
range to full scale and manufacture the difference it is meant to show. Each panel has a
`.cfg.txt` sidecar naming its full config.

**`_errhot` is the panel to look at first.** Its white wedges are the pale regions that
started this investigation, and `1_predictive` is black.

**No difference panel is rendered.** Over `t = 50` any change of step size gives a
different trajectory through a chaotic region -- the label-flip rate against the
`eta/256` ground truth is 1.0000 for a correct mode and a broken one alike, so such a
panel would be a picture of chaos with the caption of a comparison.
